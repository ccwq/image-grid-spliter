# Change: 重构紧凑导出工作区与进度反馈

## Why

当前页面在所有视口按多个面板纵向堆叠。下载进度仅显示在 Hero 统计项，不能展示当前文件和总文件数，也没有完成报告。需要在不移除任何现有能力的前提下，重新组织布局和导出反馈。经批准的进一步细化：PC 端导出动作需从结果面板头部移出，集中到一个固定在视口底部、与右侧内容栏对齐的浮动导出栏；部分导出失败的重试入口随之上移到常驻导出报告，移动端保持既有实现不变。

## What Changes

- 桌面端改为左侧紧凑控制栏与右侧上传/结果主区域。
- 桌面端（>= 960px）新增固定于视口底部、与右侧内容栏右缘对齐的浮动导出栏，常规内容仅包含队列数量、自动下载开关和一个视觉主“下载全部”按钮。
- PC 端 ResultsPanel 头部收敛为纯结果呈现（标题、汇总、折叠等），不再承载自动下载开关、“下载全部”按钮或重试入口。
- PC 端部分导出失败的重试入口移至常驻导出完成报告；移动端（< 960px）保留结果区域内既有的内联恢复入口。
- 移动端保持单页单栏，控制项折叠，上传和结果优先；MobileAdvancedDrawer、底部快捷 dock、内联自动下载控件、布局和行为保持不变。
- 所有视口使用一致的紧凑密度、深色主题和青绿色强调色。
- 增加固定顶部的分阶段进度条：生成、目录保存或传统下载触发。
- 增加完成报告：目录写入显示保存、重命名与失败数；传统下载明确显示已触发数。
- 以既有功能清单作为回归门槛，不删除上传、编辑、预览、下载、目录导出或本地化能力。

## Impact

- Affected specs: `compact-export-workspace`（新增）
- Affected code: `App.vue`、`ResultsPanel.vue`、`MobileAdvancedDrawer.vue`（只读不变更）、`ExportProgressOverlay.vue`、现有页面组件、`useImageSlicer.ts`、`useDirectoryExport.ts`、本地化和新进度组件
- Dependencies: `add-directory-batch-export` 中的目录导出 module
