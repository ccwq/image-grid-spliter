# T01 逐图删除与队列排序

Type: grilling
Status: resolved
Blocked by:

## Question

每个待切片元素（`ResultsPanel` 的 image-block）增加删除与排序操作。需决策：

1. 排序交互形态：上移/下移按钮、拖拽排序，还是输入序号？移动端（<960px 单列）如何呈现？
2. 删除单图的语义：是否等同"从队列移除"——回收该图 Object URL、其 tiles/缓存条目如何处置（保留供重新加入时命中，还是一并清除）？
3. 处理中（processing）能否删除/排序？与既有 latest-wins 补跑、重置竞态守卫如何共存？

约束：缓存淘汰不得回收界面正在使用的 URL；`addFiles` 以内容 SHA-256 去重。预算：2 轮讨论。

## Answer

（2026-11-11 讨论确定）

1. **排序交互**：上移/下移按钮。每张图片卡片（image-block）提供上移/下移小按钮，PC 与移动端同构；processing 时禁用。
2. **删除语义**：仅从队列移除。回收该图 Object URL 与 tiles 引用；切片缓存条目保留——同内容图片重新拖入时经内容 SHA-256 仍可命中缓存，符合既有 LRU 语义。
3. **处理中限制**：删除与排序按钮在 processing 时禁用，与"下载此图片"等既有按钮一致；不引入新的在途生成竞态路径。
