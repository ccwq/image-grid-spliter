# T04 每图网格覆盖与单图设置入口

Type: grilling
Status: resolved
Blocked by:

## Question

每个待切片元素可使用独立网格（覆盖全局网格），并在其内部设置按钮的 popover 中展示与全局面板相同的"网格预设 + 自定义网格"内容进行设置；同时提供"使用自定义网格"回退。需决策：

1. 覆盖模型：`ImageItem` 增加可选每图网格覆盖字段（`SlicePlan` 或 `GridIdentity` + 分割线）？无覆盖时回退全局 `useGridSettings.slicePlan`。全局改动是否仍作用于未覆盖图片？
2. 每图覆盖是否持久化（localStorage 载荷需版本升级 GRID_SETTINGS_VERSION）？重置工作区时每图覆盖随队列清空，还是保留？
3. popover 内容范围：仅预设卡片 + 自定义行列，还是含边线擦除？含边线擦除时每图各自生效，成本与收益是否匹配？
4. 设置入口位置：image-block 内的设置按钮在 PC 与移动端分别放哪里（tiles-header 区域）？popover 在移动端如何呈现（全屏层、抽屉、还是内联展开）？
5. 缓存兼容：缓存键已含每图矩形，每图不同网格天然命中不同条目；确认无需改缓存，但结果区"网格: 1 列 x 1 行"摘要需改为每图各自描述——全局摘要文案如何降级？

预算：最多 4 轮讨论。

## Answer

（2026-11-11 讨论确定，4 问收敛）

1. **覆盖模型**：`ImageItem` 增加可选每图覆盖字段（网格身份 + 分割线）。设置过的图用覆盖网格，未设置的图跟随全局；全局改动仍作用于未覆盖图片。
2. **popover 内容范围**：仅网格预设卡片 + 自定义行列（与全局面板同构）；边线擦除仍只在全局设置。popover 提供"使用自定义网格"一键回退全局。
3. **设置入口与移动端形态**：入口在每张图片卡片的 tiles-header 区（"下载此图片"旁）；PC 用 popover，移动端用全屏层展示，底部确认。
4. **持久化**：每图覆盖不写入 localStorage，随队列清空而消失；`igs:grid-settings` 载荷无需版本升级。
5. **摘要降级**：结果区顶部全局"网格： 1 列 x 1 行"摘要改为每图卡片内各自描述（利用卡片已有切片数位置）；切片缓存键已含每图矩形，无需改缓存。
