# T02 下载全部正逆序开关

Type: grilling
Status: resolved
Blocked by:

## Question

"下载全部"支持正序/逆序导出，以 checkbox 控制。需决策：

1. 逆序的作用范围：仅影响"下载全部"（目录直写写入顺序、传统逐张触发顺序），还是也影响逐图"下载此图片"？（逐图下载单文件，顺序无意义，预计排除）
2. 文件命名是否携带序号（保证文件管理器中按名排序与写入顺序一致），还是仅靠写入顺序？
3. 开关放置与持久化：与"自动下载"并列（DesktopDownloadBar PC + ResultsPanel 移动端内联区），是否持久化到 localStorage、默认正序还是逆序？

约束：ADR-0001 语义不变——目录直写失败重试仍按剩余项顺序；逆序不改变重名后缀规则。预算：2 轮讨论。

## Answer

（2026-11-11 讨论确定）

1. **作用范围**：仅影响"下载全部"的遍历顺序（目录直写写入顺序、传统逐张触发顺序）；逐图"下载此图片"不受影响。展示顺序（结果区排列）不随之变化。
2. **文件命名**：不携带序号，保持现有 `baseName + 行列` 命名与重名后缀规则不变。
3. **持久化**：checkbox 状态持久化到 localStorage（并入现有导出设置载荷），刷新后保留，默认正序。
4. ADR-0001 语义不变：逆序仅是遍历顺序反转，失败重试仍按剩余项顺序。
